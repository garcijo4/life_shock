# Life Shock Budget Simulator

This is an interactive web application that helps students practice zero-based budgeting and stress-test their finances. 

## Features
- **Zero-Based Budget Builder**: Assign every dollar of a fictional persona's income to various categories (Housing, Food, Transportation, etc.) until the balance hits exactly $0.
- **Life Shock Generator**: Randomly encounter a "life shock" (e.g., car repair, medical bill) and adjust the budget to absorb it.
- **Stress Test Defense**: Write 3-4 sentences defending the two choices changed in the budget and explaining why.
